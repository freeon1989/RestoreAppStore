# Privacy policy

RestoreAppStore runs on your computer. It does not include telemetry and does not send usage reports to the author.

## Data the program uses

- **Apple ID.** Sign-in happens with Apple. The program talks to Apple's servers on your behalf to list purchase history and download IPA files that already belong to that account. Passwords are not written to disk.
- **Device connection.** If you choose to install an IPA, the program talks to the connected iPhone or iPad over USB through Apple's official Apple Devices support on Windows.
- **Local files.** Downloaded IPA files, logs and settings stay on this computer (including under `%LOCALAPPDATA%\RestoreAppStore`).
- **Updates.** If the in-app updater is used, the program contacts GitHub (`api.github.com` and GitHub release download hosts) to check the latest version and to download a release archive. That request uses your IP address like any other HTTPS request. It does not include your Apple ID or device data. The check can be skipped, and an update is installed only after you click the button.

The program does not create an account with the author and does not upload your files, Apple ID or device identifiers to any server operated by the project.

## This website and GitHub

The project is hosted on GitHub. Visiting GitHub pages or downloading a release is subject to [GitHub's privacy statement](https://docs.github.com/en/site-policy/privacy-policies/github-privacy-statement).
